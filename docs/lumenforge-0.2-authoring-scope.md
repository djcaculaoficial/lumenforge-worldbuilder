# Lumenforge 0.2 Authoring Scope

Lumenforge 0.2 is a **local, procedural, 2D narrative-adventure creator**. It is built for a creator to begin with an empty project, compose an illustrated scene with the built-in procedural scene kit, connect interactions to dialogue and choices, set state effects, move between rooms, and run the result in an embedded preview.

| Authoring area | Functional in the 0.2 target |
| --- | --- |
| Project | New empty project, title, story premise, import/export, local persistence |
| Rooms | Add, select, duplicate, rename, set atmosphere and entry node |
| Elements | Add from a bounded local scene kit; position, scale, palette, layer, label and visibility |
| Interactions | Turn an element into a hotspot and target a dialogue node or another room |
| Narrative | Create and edit dialogue, choice, and consequence nodes; author bodies, effects and targets |
| State | Add boolean, integer and string variables and edit their values |
| Timeline | Add and inspect timing beats for camera, character, dialogue and sound direction |
| Preview | Traverse authored rooms, dialogue, choices and supported state effects without network access |

The 0.2 target deliberately does not claim arbitrary image import, freeform drawing, audio generation, sprite rigging, code compilation, or standalone game exporting. These are potential subsequent development areas, but they are outside the functional promises of this release.
